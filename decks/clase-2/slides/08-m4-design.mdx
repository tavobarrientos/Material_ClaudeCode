```markdown
## Decisions
- Columna `min_stock INTEGER NOT NULL DEFAULT 0` en products
- Migración nueva con drizzle-kit; no se edita ninguna existente
- `GET /api/products?lowStock=true` filtra stock <= min_stock
- Badge en `ProductTable` y página `/inventory/restock`
## Contract between tasks
- Campo: `min_stock` (number) · Query param: `lowStock`
- Componente: `<LowStockBadge stock min />`
## Risks
- Productos existentes quedan con 0 → sin alertas hasta configurarlos
```
