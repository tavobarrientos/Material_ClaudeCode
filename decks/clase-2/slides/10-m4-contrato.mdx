## Las reglas de tasks.md

<TwoCol>
  <Col title="Al escribirlo">
    - Una tarea = un resultado verificable
    - `[P]` solo si los archivos no se cruzan
    - Bloques en orden de dependencia
    - Cada tarea cabe en una sesión
  </Col>
  <Col title="Al ejecutarlo">
    - Leer tasks.md **antes** de empezar
    - Marcar `[x]` al terminar cada tarea
    - Nunca reescribir tareas ajenas
    - Si algo cambia, se edita la spec primero
  </Col>
</TwoCol>

<Callout>tasks.md es el **tablero del team**: si no se actualiza, nadie sabe qué falta.</Callout>
