## El subagent que hace de todo

<Pitfall>
  <Anti>Un solo "dev-agent" con todas las tools y una description vaga como "ayuda con el código". Claude no sabe cuándo usarlo y el resultado regresa como un muro de texto.</Anti>
  <Fix>Agentes con una responsabilidad, description que diga cuándo usarlos y un formato de respuesta fijo (archivos tocados, decisiones, pendientes).</Fix>
</Pitfall>
