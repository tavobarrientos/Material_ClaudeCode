## Subagents vs Agent Teams

<Compare>
  <Col title="Subagents">
    - Viven dentro de una sesión
    - Solo hablan con el agente principal
    - Regresan un resumen y terminan
    - Ideal: tareas cortas y aisladas
  </Col>
  <Col title="Agent Teams">
    - Cada teammate es una **sesión completa** de Claude Code
    - Se comunican por **mailbox**
    - Comparten una **task list**
    - Ideal: features con varias partes en paralelo
  </Col>
</Compare>

<Callout>Subagents delegan. Un Agent Team **coordina**.</Callout>
